# Glossary

The words the code uses. New concepts get a term here before they get a name in code.

- **Sidebar**: the extension's side panel showing native bookmarks above the tabs of the window it sits in; one independent instance per window. It changes bookmarks only through a Bookmark edit. Not a tab-strip replacement: Chrome's own tab strip stays.
- **Bookmark edit**: one change a person makes to native bookmarks in the Sidebar: a move (drag or ⌥↑/↓), an edit of title/URL, a delete, a new folder, adding a bookmark (a dropped tab, Add current tab, Bookmark tab), or saving tabs as a folder (a dropped Group header, Save group to bookmarks, Bookmark all tabs). The nightly sweep never makes one.
- **Drop place**: where a dragged bookmark, tab or Group header would land (a parent folder and an index in `chrome.bookmarks` coordinates), or none when the drop isn't allowed.
- **Bookmark icon**: an emoji a person picks for a bookmark or folder in the Sidebar's editor — or, for a folder, a **folder colour** (one of Chrome's tab-group colours) — shown instead of its site icon or plain folder icon; stored in the extension's storage per profile, keyed by bookmark ID, so it doesn't sync to other devices.
- **Site icon**: a bookmark's or tab's favicon — from Chrome's favicon cache, or, for a bookmark Chrome has none for and when the setting is switched on (off by default), fetched from the bookmark's own site (`/favicon.ico`, then `/apple-touch-icon.png`); what a lookup found is remembered per site for 7 days, "none" for 1 day.
- **Tab group**: one of Chrome's own open tab groups in the Sidebar's window (title, colour, collapsed or not, its tabs contiguous on the tab strip). The Sidebar reads and changes it only through Chrome's tab-group API, which sees open groups only.
- **Saved tab groups**: Chrome's own list of tab groups kept for reopening, its closed ones included. Extensions can't read it. Close group leaves a group in it; Ungroup and Delete group take it out, as Chrome's own menu does.
- **Group header**: the Tabs row standing for one Tab group: a pill in the group's colour with its title (an untitled group: no text). Expanding or collapsing it expands or collapses the group in Chrome, and the other way round; its tabs follow it, indented, while it's expanded. Its menu holds Chrome's group commands.
- **Open All**: a folder menu's way to open the folder's own bookmarks (not its subfolders'), as Chrome's bookmark bar does (Chromium's `OpenAllIfAllowed`): as background tabs at the end of this window, in a new window (the first selected), in a new incognito window (Chrome's own pages left out), or in a new Tab group named after the folder (in its folder colour, if it has one). From 15 bookmarks on it asks first.
- **Tab menu**: a tab row's right-click menu (Shift+F10): the commands of Chrome's own tab menu that its extension API can carry out, on that one tab. "Below" in the Sidebar is Chrome's "to the right".
- **Close other tabs / Close tabs below**: the Tab menu's closes, as Chrome's own (Chromium's `GetTabsClosedByCommand`): every other tab of the window (or every one below the tab), except pinned tabs and the tab's Split View partner; tabs in groups too. A group all of whose tabs close is closed whole and stays in Saved tab groups; Undo reopens the other tabs in place, back in their groups.
- **Loose tab**: a tab of the Sidebar's window in no Tab group and not pinned.
- **Tidy**: the Tabs heading's button that closes the Sidebar's window's Loose tabs except the selected one; tabs in a group and pinned tabs stay. Undo reopens them in place, without their back history.
- **Undo**: reverses the last Bookmark edit (or a close of several tabs: Tidy, Close other tabs, Close tabs below, Delete group) of that window's Sidebar; ends with the next edit or a panel reload. Undoing a delete recreates the bookmarks with new IDs; undoing a saved group removes its folder whole (only while it holds just what was saved); reopened tabs go back into their group if it's still open, else into a new group with its title and colour.
- **Folding**: which bookmark folders are expanded and which Sidebar sections (Bookmarks, Tabs) are folded; remembered per profile, shared by every window's Sidebar.
- **Colour treatment**: the Sidebar's palette, Neutral (Chrome-like, the default) or Warm; each follows the system's light/dark setting.
- **Navigation footprint**: horizontal pixels the window spends on navigation UI (native tab strip or rail + side panel); the page keeps the rest.
- **Tab instance**: one currently open tab. IDs are session-scoped; a URL alone is not an instance identity.
- **Last use**: the most recent time a tab instance was switched to (Chrome's `lastAccessed`, or the extension's in-session record of activation) or deliberately navigated (a committed navigation that is not a reload). A restored tab with no use since Chrome launched has no in-session last use.
- **Nightly sweep**: one serialized pass per day, at 03:00 local or the first moment Chrome runs after it (wake or launch), that closes tab instances outside the recent-use guard; it never touches bookmarks. Off unless switched on.
- **Recent-use guard**: the window (3 hours) before a nightly sweep; a tab whose last use falls inside it, the focused window's selected tab, an audible tab, a pinned tab and a tab in a tab group survive the sweep.
- **Placeholder tab**: a New Tab page opened before a window's last tab is closed (by the sweep or from the Sidebar), so the window is never closed.
